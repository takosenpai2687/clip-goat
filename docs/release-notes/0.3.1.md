## 下载

- **Windows 10/11（64 位）**：`Clip-Goat-Setup-0.3.1.exe`。0.2.0 及以后的版本可以在应用内更新；0.1.0 需要手动安装一次。安装包没有代码签名，首次运行时 Windows 会显示 SmartScreen 提示，选择"更多信息 → 仍要运行"。
- **macOS（Apple Silicon）**：`Clip-Goat-0.3.1-mac-arm64.dmg`。由自动构建生成，**没有在实机上测试过**。它没有 Apple 开发者签名，首次打开前将应用拖进"应用程序"，在终端执行 `xattr -cr "/Applications/Clip Goat.app"`。macOS 上没有应用内更新，也不能撤销删除。

`latest.yml` 和 `.blockmap` 供 Windows 应用内更新使用，不需要下载。

## 变更

- 纯音频默认保持输入格式导出，例如 MP3 导出为 MP3，不再统一导出为 M4A。优先流复制，需要时使用该格式支持的编码重新编码
- 声道处理输出单声道；纯音频保持输入格式，视频继续使用原有导出格式和关键帧策略

## Download

- **Windows 10/11 (64-bit)**: `Clip-Goat-Setup-0.3.1.exe`. Version 0.2.0 and later can update from inside the app; version 0.1.0 needs one manual install. The installer is not code-signed, so Windows shows a SmartScreen prompt the first time it runs; choose "More info → Run anyway".
- **macOS (Apple Silicon)**: `Clip-Goat-0.3.1-mac-arm64.dmg`. It comes from an automated build and **has not been tested on a real Mac**. It has no Apple developer signature; before opening it, drag the app to Applications and run `xattr -cr "/Applications/Clip Goat.app"` in Terminal. On macOS there are no in-app updates and a delete cannot be undone.

`latest.yml` and the `.blockmap` file are used by Windows in-app updates and do not need to be downloaded.

## Changed

- Audio-only clips now default to the input format, such as MP3 to MP3, instead of always exporting to M4A. Stream copy is preferred; when needed, audio is re-encoded with a codec supported by the format
- Channel processing outputs mono audio; audio-only clips retain the input format, and video keeps the existing output format and keyframe strategy
