## 下载

- **Windows 10/11（64 位）**：`Clip-Goat-Setup-0.2.1.exe`。已安装 0.2.0 的可以直接在应用内更新；0.1.0 需要手动安装一次。安装包没有代码签名，首次运行时 Windows 会显示 SmartScreen 提示，选择"更多信息 → 仍要运行"。
- **macOS（Apple Silicon）**：`Clip-Goat-0.2.1-mac-arm64.dmg`。这是第一个 macOS 版本，由自动构建生成，**没有在实机上测试过**。它没有 Apple 开发者签名，首次打开会被系统拦截；把应用拖进"应用程序"后在终端执行 `xattr -cr "/Applications/Clip Goat.app"`，再打开。macOS 上没有应用内更新，也不能撤销删除。

`latest.yml` 和 `.blockmap` 供应用内更新使用，不需要下载。

## Download

- **Windows 10/11 (64-bit)**: `Clip-Goat-Setup-0.2.1.exe`. Version 0.2.0 can update from inside the app; version 0.1.0 needs one manual install. The installer is not code-signed, so Windows shows a SmartScreen prompt the first time it runs; choose "More info → Run anyway".
- **macOS (Apple Silicon)**: `Clip-Goat-0.2.1-mac-arm64.dmg`. This is the first macOS build. It comes from an automated build and **has not been tested on a real Mac**. It has no Apple developer signature, so macOS blocks it on first launch; drag the app to Applications, run `xattr -cr "/Applications/Clip Goat.app"` in Terminal, then open it. On macOS there are no in-app updates and a delete cannot be undone.

`latest.yml` and the `.blockmap` file are used by in-app updates and do not need to be downloaded.

## Added

- Previous and next video buttons in the bottom-left corner of the preview; they move through the current folder in list order and grey out at either end
- A progress bar along the bottom of the preview that can be clicked and dragged, in step with the timeline
- The workspace can be resized by dragging its right edge; double-click to reset
- A macOS (Apple Silicon) build

- The update check uses an up-arrow icon
- The title bar no longer has an Open video button; `Ctrl+O` and drag-and-drop still open files
