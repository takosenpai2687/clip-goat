## 下载

- **Windows 10/11（64 位）**：`Clip-Goat-Setup-0.3.0.exe`。0.2.0 及以后的版本可以直接在应用内更新；0.1.0 需要手动安装一次。安装包没有代码签名，首次运行时 Windows 会显示 SmartScreen 提示，选择"更多信息 → 仍要运行"。
- **macOS（Apple Silicon）**：`Clip-Goat-0.3.0-mac-arm64.dmg`。由自动构建生成，**没有在实机上测试过**。它没有 Apple 开发者签名，首次打开前将应用拖进"应用程序"，在终端执行 `xattr -cr "/Applications/Clip Goat.app"`。macOS 上没有应用内更新，也不能撤销删除。

`latest.yml` 和 `.blockmap` 供 Windows 应用内更新使用，不需要下载。

## 新增

- 支持截取和拼接音频，默认导出为 M4A；桌面端和 CLI 共用裁剪逻辑
- 音频和带音轨的视频都可使用声道工作台：实时试听、查看左右耳波形，选择保持原样、左右合并、仅左声道或仅右声道
- 支持选择试听和导出的音轨，默认保留全部音轨
- CLI 新增 `--audio-mode` 和 `--audio-track` 参数

声道处理输出单声道 AAC，双耳播放同一份声音；左右合并不是自动响度均衡，会失去立体声空间感，反相声音也可能抵消。视频画面是否重新编码仍由关键帧决定。

## 变更

- 左右方向键改为后退 / 前进一个跨度，默认为 5 秒；时间轨手柄聚焦时仍可用方向键微调

## Download

- **Windows 10/11 (64-bit)**: `Clip-Goat-Setup-0.3.0.exe`. Version 0.2.0 and later can update from inside the app; version 0.1.0 needs one manual install. The installer is not code-signed, so Windows shows a SmartScreen prompt the first time it runs; choose "More info → Run anyway".
- **macOS (Apple Silicon)**: `Clip-Goat-0.3.0-mac-arm64.dmg`. It comes from an automated build and **has not been tested on a real Mac**. It has no Apple developer signature; before opening it, drag the app to Applications and run `xattr -cr "/Applications/Clip Goat.app"` in Terminal. On macOS there are no in-app updates and a delete cannot be undone.

`latest.yml` and the `.blockmap` file are used by Windows in-app updates and do not need to be downloaded.

## Added

- Cut and join audio, exporting to M4A by default; the desktop app and CLI share the same clipping logic
- Use the channel workbench with audio or video containing audio: preview the output, see left and right waveforms, and choose original, merged, left-only or right-only
- Select the audio track to preview and export, or keep all tracks by default
- New CLI options: `--audio-mode` and `--audio-track`

Channel processing outputs mono AAC, playing the same sound in both ears. Merging channels is not automatic loudness balancing: stereo separation is lost, and out-of-phase sounds can cancel. Video re-encoding still depends on keyframes.

## Changed

- The left and right arrow keys now skip backward or forward by an interval (5 seconds by default); they still fine-tune timeline handles when those are focused
