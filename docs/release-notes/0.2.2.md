## 下载

- **Windows 10/11（64 位）**：`Clip-Goat-Setup-0.2.2.exe`。0.2.0 及以后的版本可以直接在应用内更新；0.1.0 需要手动安装一次。安装包没有代码签名，首次运行时 Windows 会显示 SmartScreen 提示，选择"更多信息 → 仍要运行"。
- **macOS（Apple Silicon）**：`Clip-Goat-0.2.2-mac-arm64.dmg`。由自动构建生成，**没有在实机上测试过**。它没有 Apple 开发者签名，首次打开会被系统拦截；把应用拖进"应用程序"后在终端执行 `xattr -cr "/Applications/Clip Goat.app"`，再打开。macOS 上没有应用内更新，也不能撤销删除。

`latest.yml` 和 `.blockmap` 供应用内更新使用，不需要下载。

## 变更

- 片段的文件名改为 `{原文件名}_clip_{时长}s.mp4`，例如 `Game_clip_12.5s.mp4`，不再写起点和终点。起止时间仍记录在文件元数据里；旧名字的片段照常识别，不会被改名
- 标题栏的更新按钮旁显示当前版本号

## Download

- **Windows 10/11 (64-bit)**: `Clip-Goat-Setup-0.2.2.exe`. Version 0.2.0 and later can update from inside the app; version 0.1.0 needs one manual install. The installer is not code-signed, so Windows shows a SmartScreen prompt the first time it runs; choose "More info → Run anyway".
- **macOS (Apple Silicon)**: `Clip-Goat-0.2.2-mac-arm64.dmg`. It comes from an automated build and **has not been tested on a real Mac**. It has no Apple developer signature, so macOS blocks it on first launch; drag the app to Applications, run `xattr -cr "/Applications/Clip Goat.app"` in Terminal, then open it. On macOS there are no in-app updates and a delete cannot be undone.

`latest.yml` and the `.blockmap` file are used by in-app updates and do not need to be downloaded.

## Changed

- Clips are named `{original-name}_clip_{length}s.mp4`, for example `Game_clip_12.5s.mp4`, instead of carrying their start and end. The start and end are still recorded in the file metadata; clips with the old names are recognised as before and are not renamed
- The title bar shows the current version next to the update button
